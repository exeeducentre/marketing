Matematika Wajib - Materi Himpunan Bilangan
Diberikan tiga himpunan bilangan sebagai berikut:
$$A = \{x \mid x < 6, x \in \text{Bilangan Asli}\}$$ $$B = \{x \mid x \text{ bilangan genap}, x \in \text{Bilangan Cacah}\}$$ $$C = \{x \mid x \le 10, x \in \text{Bilangan Prima}\}$$
Berdasarkan himpunan-himpunan tersebut, hasil dari $(A \cap B) \cup C$ adalah ....
$\bigcirc \; \text{(A)} \;\; \{2, 3, 5, 7\}$
$\bigcirc \; \text{(B)} \;\; \{0, 2, 3, 5, 7\}$
$\bigcirc \; \text{(C)} \;\; \{2, 3, 4, 5, 7\}$
$\bigcirc \; \text{(D)} \;\; \{0, 2, 3, 4, 5, 7\}$
$\bigcirc \; \text{(E)} \;\; \{2, 3, 4, 5, 7, 10\}$

STRATEGI PENYELESAIAN 💡
Langkah pertama yang paling aman dalam soal himpunan adalah mendaftarkan seluruh anggota dari masing-masing himpunan terlebih dahulu. Hati-hati dengan definisi Asli, Cacah, dan Prima!
Himpunan A (Bil. Asli < 6)
$\boldsymbol{A = \{1, 2, 3, 4, 5\}}$
Himpunan B (Bil. Genap Cacah)
$\boldsymbol{B = \{0, 2, 4, 6, 8, \dots\}}$
Himpunan C (Bil. Prima $\le$ 10)
$\boldsymbol{C = \{2, 3, 5, 7\}}$
LANJUT SWIPE ➡️
exeeducentre.com
LANGKAH 1: IRISAN $(A \cap B)$
Kerjakan operasi di dalam kurung terlebih dahulu. Tanda irisan $(\cap)$ berarti kita hanya mengambil angka yang SAMA-SAMA ADA di Himpunan A dan B.
$$A = \{1, \color{red}{\boldsymbol{2}}, 3, \color{red}{\boldsymbol{4}}, 5\}$$
$$B = \{0, \color{red}{\boldsymbol{2}}, \color{red}{\boldsymbol{4}}, 6, 8, \dots\}$$
Angka yang beririsan (ada di keduanya) adalah 2 dan 4. Maka:
$$(A \cap B) = \{2, 4\}$$
SEDIKIT LAGI ➡️
exeeducentre.com
LANGKAH 2: GABUNGAN $(\cup)$
Selanjutnya, gabungkan hasil irisan tadi dengan Himpunan C. Tanda gabungan $(\cup)$ berarti kita MEMASUKKAN SEMUA anggotanya.
Hasil Irisan: $\quad (A \cap B) = \{\boldsymbol{2, 4}\}$
Himpunan C: $\quad C = \{\boldsymbol{2, 3, 5, 7}\}$
Gabungkan semuanya (jangan tulis angka dobel):
$$(A \cap B) \cup C = \{\boldsymbol{2, 3, 4, 5, 7}\}$$
Hasilnya adalah $\{2, 3, 4, 5, 7\}$
Jawaban yang paling tepat adalah: (C)

WAKTUNYA BERLATIH 📝
Pola soal tentang himpunan bilangan ini hampir PASTI keluar lagi dengan modifikasi angka. Coba tes kemampuanmu yuk!
Diberikan tiga himpunan bilangan sebagai berikut:
$$P = \{x \mid x < 8, x \in \text{Bil. Asli}\}$$ $$Q = \{x \mid x \text{ bilangan ganjil}, x \in \text{Bil. Cacah}\}$$ $$R = \{x \mid x < 10, x \in \text{Bil. Prima}\}$$
Berapakah hasil dari $(P \cap Q) \cup R$?
$\bigcirc \; \text{(A)} \;\; \{1, 3, 5, 7\}$
$\bigcirc \; \text{(B)} \;\; \{2, 3, 5, 7\}$
$\bigcirc \; \text{(C)} \;\; \{1, 2, 3, 5, 7\}$
$\bigcirc \; \text{(D)} \;\; \{1, 2, 3, 4, 5, 7\}$
$\bigcirc \; \text{(E)} \;\; \{1, 2, 3, 5, 7, 9\}$
